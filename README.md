# Orbit AI

Orbit is a self-hostable AI assistant starter with:
- Responsive Orbit chat interface
- Email/password sign-up and sign-in
- Saved conversations in PostgreSQL
- Free text AI chat through Vireonix, with no API key or billing account required by the provider
- Render deployment configuration

## What works in this no-key version

Text chat uses Vireonix's public, keyless chat endpoint. It has fair-use/IP limits and no service-level guarantee, so responses can be temporarily unavailable or rate-limited. Because this starter calls the provider from the server, requests may share the deployed server's provider-side IP quota. Read the provider's terms and privacy information before inviting other people to use the app.

**Image understanding and AI image generation are not enabled in this version.** The UI may still show those controls, but the server returns a clear message instead of pretending they work. These features require a compatible service.

## Deploy to Render

1. Download and unzip this project.
2. Create a GitHub repository named `orbit-ai`.
3. Upload the **contents** of this folder to the repository (not an extra nested `orbit-ai/orbit-ai` folder). Do not upload secrets or `.env` files.
4. In Render, choose **New → Blueprint** and connect your GitHub repository. Render reads `render.yaml` and proposes the web service plus PostgreSQL database.
5. Deploy and wait for the build and health check to finish.
6. Open the `https://your-service-name.onrender.com` URL shown by Render.

`JWT_SECRET` is generated by the Render Blueprint. `DATABASE_URL` is connected from the database defined in `render.yaml`. If Render does not offer the configured free database plan, select a database plan available to your account and connect its internal connection string. Availability and pricing can change.

## Run locally

You need Node.js 20+ and PostgreSQL. Set `JWT_SECRET` and `DATABASE_URL` in `.env`, then run:

```bash
npm install
npm run dev
```

Open `http://localhost:5173`. The Vite dev server forwards `/api` requests to the local server on port 10000.

For a production build:

```bash
npm run build
npm start
```

## Environment variables

| Variable | Required | Purpose |
|---|---|---|
| `JWT_SECRET` | Yes | Signs login sessions; Render generates one in the Blueprint |
| `DATABASE_URL` | Yes | PostgreSQL connection string |
| `PORT` | No | Defaults to `10000`; Render sets this automatically |

## Notes

- This is a starter app, not a guarantee that Orbit can answer every question correctly.
- Free provider access and Render's free offerings may change or have limits.
- Before public production use, add abuse protection, privacy disclosures, password reset/email verification, and monitoring.
